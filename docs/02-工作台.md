# 02 工作台

工作台是编排与观测的中心。顶部是全局栏：品牌链接（回集群总览）与实时
连接徽标（● 实时 / ◐ 已降级 / ○ 离线）。

## 集群总览 `/fleet`

每位 Yuki 一张卡片：

- **状态**：活跃（有 Run 在跑）/ 等待（有待确认草案）/ 空闲。
- **头条**：最早开始的活跃 Run 的阶段徽标 + objective。
- **统计**：活跃 Run 数与 Worker 总数。
- **提醒**：「N 份派发草案待确认」（若有）。

卡片按 活跃 → 等待 → 空闲 排序，同级按最近交付时间。点卡片进入该
Yuki 的工作台「现在」视图。

## 现在 `/yuki/:id/now`

这位 Yuki 此刻的全景：

- **等待用户**：待确认的派发草案（标题 + 生成方式徽标）。点击打开草案
  编辑器。
- **活跃 Run 树**：主对话 Run、各任务 Run 为根，Worker 缩进嵌套。每个
  Run 一张状态卡（见下）。
- **最近交付**：最近 5 条交付记录（类型图标 + 标题 + 相对时间）。

无活跃工作时显示空态与主对话入口。

## 状态卡（RunStatusCard）

每个活跃 Run 一张，全部数据来自遥测推送：

| 元素 | 含义 |
| --- | --- |
| 阶段徽标 | 运行 / 等待工具 / 压缩上下文 / 睡眠 / 取消中 |
| objective | 该 Run 的首条输入摘要 |
| 轮次 x/y | 已用模型轮次 / 上限（`YUKI_MAX_TURNS`） |
| 模型 | 实际模型 |
| token | ↑ 输入累计 ↓ 输出累计 |
| 上下文条 | 估算 token / 压缩触发线（无数据时隐藏） |
| ⚙ 工具 | 进行中的工具调用与各自耗时 |
| 已耗时 | 从启动到现在的秒级计时 |
| Worker ×n | 活跃子 Worker 数 |

操作：**[监控]** 进入 Run 监控；**[steer]** 展开行内输入，向该 Run 注入
一句引导（Worker 同样可以直达）；**[取消]** 二次点击确认后终止该 Run
（其未完成 Worker 会被级联取消）。

## 主对话 `/yuki/:id/chat`

与这位 Yuki 的默认交互界面：

- 流式消息、推理（可折叠）、工具调用卡、子代理卡、确认卡。
- 运行中：输入框变为 steer，出现取消按钮；失败后可重试。
- 头部有「派发任务」入口（见 [03-派发任务](03-派发任务.md)）。
- Yuki 调用 `propose_dispatch` 时，对话流内出现**派发卡片**：可编辑
  标题与 Prompt，确认或取消；确认后工具解阻，Yuki 得知任务已开立。
- 主对话不可归档、不可删除、不出现在任务列表。

任务对话 `/yuki/:id/chat/:threadId` 是同一组件，承载某个任务的独立对话。

## 任务 `/yuki/:id/tasks`

这位 Yuki 的全部持久任务：标题、归档徽标、活跃徽标、最后活跃时间。
点击行进入该任务的对话。

## 交付 `/yuki/:id/deliveries`

时间倒序的交付流：

- **答案**：根 Run 的最终回答（链接到对应任务对话）。
- **文件**：经写工具创建/修改的文件（路径可复制）。
- **artifact**：工具输出溢出产生的内容（可展开查看）。

可按类型过滤（全部/答案/文件/artifact），分页加载。

## 变更 `/yuki/:id/changes`

文件系统变更台账：路径、操作徽标（created/modified/deleted）、来源徽标
（工具名 / git）、任务、时间。展开行显示 unified diff（绿增红删）；git
补记的行只显示 stat 并注明「内容以工作区为准」。可按任务过滤。

> 注意：非 git 目录中 shell 命令造成的文件改动**不在**台账内（见
> [10-已知限制](10-已知限制.md)）。

## Run 监控 `/yuki/:id/run/:runId`

单个 Run 的钻取终点：

- **活跃 Run**：状态卡 + Worker 子树（可继续点入）+ steer/取消 + 该
  Run 的交付与变更。
- **历史 Run**（已结束）：「已结束」头 + Journal 摘要（轮次、工具调用
  数、token、耗时）+ 该 Run 的交付与变更（台账是持久的）。
