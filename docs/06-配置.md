# 06 配置

全部配置经环境变量传入（启动器 `./yuki` 继承当前环境）。改动后需重启。

## 模型与 provider

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `YUKI_PROVIDER` | `deepseek` | 主 provider 名 |
| `YUKI_MODEL` | DeepSeek V4 Flash | 主模型 |
| `YUKI_BASE_URL` | DeepSeek 官方 | OpenAI 兼容端点 |
| `YUKI_API_KEY` | — | 主 provider 密钥（也可用 `DEEPSEEK_API_KEY`） |
| `YUKI_API_DIALECT` | `deepseek` | API 方言 |
| `YUKI_REASONING_EFFORT` / `YUKI_THINKING` | provider 默认 | 推理强度 |
| `YUKI_MAX_TOKENS` | provider 默认 | 单次回答输出上限 |
| `YUKI_CONTEXT_TOKENS` | 内置表 | 模型上下文窗口（未知模型须显式设置） |
| `YUKI_FALLBACK_PROVIDERS` | 空 | 失败时的后备 provider 链 |
| `YUKI_PROVIDER_RETRIES` | 3 | 可重试错误的重试次数 |
| `YUKI_MEMORY_MODEL` | 同主模型 | 内部调用（草案生成、睡眠、印象）专用模型 |
| `providers.json`（`YUKI_DATA_DIR` 下） | — | 多 provider 注册表（名称、端点、密钥引用） |

## 运行边界

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `YUKI_HOST` | `127.0.0.1` | 监听地址 |
| `YUKI_PORT` | `18080` | 后端端口 |
| `YUKI_CORS_ORIGIN` | 关 | 跨域来源 |
| `YUKI_WORK_DIR` | 项目根 | 新任务继承的工作目录 |
| `YUKI_MAX_TURNS` | 32 | 单次 Run 的本地轮次保护，触顶返回 `MAX_TURNS_EXCEEDED` |
| `YUKI_TOOL_EXECUTION` | parallel | 同轮多工具调用的执行方式 |

## 编排

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `YUKI_SUBAGENT_DEPTH` | 1 | 委派深度；1 表示 Worker 不可再委派 |
| `YUKI_SUBAGENT_MAX_PARALLEL` | 4 | 单 Run 同时活跃的异步 Worker 上限 |
| `YUKI_DISPATCH_GENERATE_TIMEOUT` | 20（秒） | 派发草案模型起草超时（超时回退为原文） |
| `YUKI_DISPATCH_CONFIRM_TIMEOUT` | 600（秒） | `propose_dispatch` 等待用户裁决的超时 |

## 上下文与压缩

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `YUKI_CONTEXT_RESERVE_TOKENS` | 16384 | 预留 token；越大越早触发压缩 |
| `YUKI_CONTEXT_KEEP_UNITS` | 12 | 压缩后保留的最近因果轮组数 |
| `YUKI_CONTEXT_SUMMARY_TOKENS` | 2048 | 旧上下文摘要上限（最小 96） |
| `YUKI_SPLICE_CHARS` / `YUKI_SPLICE_KEEP` | 内置 | 工具结果溢出为 artifact 的阈值 |

## 遥测与台账

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `YUKI_TELEMETRY_GIT` | 1 | git 增强开关；`0` 关闭 |
| `YUKI_TELEMETRY_GIT_TIMEOUT` | 3（秒） | git status/diff 超时 |
| `YUKI_TELEMETRY_DIFF_BYTES` | 8192 | 变更台账 diff 截断上限 |

## 数据目录

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `YUKI_DATA_DIR` | `~/.yuki-n` | 全部本地状态根目录 |
| `YUKI_MEMORY_DIR` | `YUKI_DATA_DIR` | 认知体系（cognition-v2）根 |
| `YUKI_JOURNAL_DIR` / `YUKI_ARTIFACT_DIR` / `YUKI_TRANSCRIPT_DIR` | `YUKI_DATA_DIR` | 分项覆盖（一般不需要动） |

## 任务级覆盖（ThreadConfig）

主对话与每个任务都可以有自己的一份配置（存于
`threads-config/<thread>.json`）：cwd、provider、model、effort、
fs/shell/memory gate、上下文策略。留空即继承全局。

继承顺序：**任务自身 → 主对话（Yuki 级默认）→ 全局**。

当前版本须通过 API 修改（`PUT /config/threads/:id`，见
[07-HTTP与事件](07-HTTP与事件.md)）；派发任务时的能力快照取自主对话配置。
