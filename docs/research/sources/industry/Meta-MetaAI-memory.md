# Meta AI Memory | Meta

Source: https://about.fb.com/news/2025/01/building-toward-a-smarter-more-personalized-assistant/
Published: January 27, 2025

## Memory feature (Jan 2025)

- At close of 2024, Meta began rolling out a feature that lets Meta AI remember certain details you share with it in 1:1 chats on WhatsApp and Messenger, to personalize future responses.
- **Memory Boost**: tell Meta AI to remember things (e.g., "I love to travel and learn new languages"); it can also pick up important details based on context.
- Example: user asks for breakfast ideas, replies "I'm a vegan" → Meta AI remembers and uses it to inform future recipe recommendations.
- Rolled out to Meta AI on Facebook, Messenger, WhatsApp for iOS/Android in US and Canada.
- Meta AI only remembers certain things told in **1:1 conversations (not group chats)**; users can delete its memories at any time.

## Meta AI app (April 2025)

- Meta AI app: assistant that gets to know preferences, remembers context, personalized.
- Can draw on info already shared on Meta products (profile, content liked/engaged with). With Facebook + Instagram in same Accounts Center, draws from both.
- Cross-device continuity: pick up conversations from glasses to app/web.

## Muse Spark 1.1 (Meta Superintelligence Labs, 2026)

- Muse Spark 1.1 actively manages its context window of **1 million tokens**. It "remembers actions, retrieves information from much earlier work, and compacts in a way that keeps the critical steps needed for later work."
- Public preview of Meta Model API for developers (June 2026).
- Meta AI (Muse Spark 1.1): can make plans, connect to email/calendar, create slides, handle tasks (July 2026).
- Incognito chats for fully private conversations.

Note: Meta has not published detailed technical architecture of its memory system (vector/graph/structured) publicly as of mid-2026; the public materials emphasize 1:1 chat memory, personalization from Meta platform data, and model-level context management (Muse Spark 1M context + compaction).
