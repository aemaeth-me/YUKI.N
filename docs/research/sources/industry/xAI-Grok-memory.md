# Grok Memory — xAI

Sources:
- xAI consumer FAQ (https://x.ai/legal/faq), Grok docs (https://docs.x.ai/grok/faq, /grok/overview)
- Announcements via Grok on X (April 17, 2025)

## What it is

Grok memory (announced April 2025, beta) lets the chatbot remember certain information from past conversations and reference it in future chats to deliver more personalized responses. Similar to ChatGPT and Gemini.

- Available on grok.com and the official iOS/Android apps (not initially in EU or UK due to privacy regulations).
- Available to free and paid tiers.
- "Memories are transparent: you can see exactly what Grok knows and choose what to forget."

## How it works

- Grok picks up details about likes, dislikes, preferences, and interests from conversations and uses them to tailor responses.
- **Referenced Chats**: when a response draws on past interactions, an icon appears at the bottom of the output; tapping it opens a sidebar showing the specific memories used to generate the response. Users can delete memories from the sidebar (web interface initially).
- Controls: Settings > Data Controls > "Personalize with Memories" toggle to disable. Individual memories can be deleted.
- **Private Chat mode** (ghost icon): stops Grok from storing chat content or using it for personalization.
- iOS: "Personalize with Memories" disabled by default (opt-in).

## Consumer model / privacy

- Memory covered under xAI consumer FAQs; on X the service follows X terms/privacy.
- Memory feature rollout and deletion initially limited to web interface.

## 2025-2026 status

- Rolling out June 2026: Grok moved to a shared weekly usage pool for paid users; docs consolidated at docs.x.ai/grok. Grok's consumer memory persists as a core personalization feature.
- No public technical details on underlying memory architecture (vector store, summaries, etc.) have been published by xAI at this level; API docs focus on model usage rather than a memory API.
