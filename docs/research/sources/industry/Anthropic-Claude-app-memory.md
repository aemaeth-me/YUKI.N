Memory now rolling out to Pro and Max plan users. Like Team and Enterprise users, you get:

- full control to view and edit what Claude remembers

## Original announcement (Sept 11, 2025)

Introducing memory to the Claude app, where Claude remembers you and your team's projects and preferences, eliminating the need to re-explain context.

- Memory is fully optional, with granular user controls.
- Incognito chats that don't appear in your conversation history or save to memory. Available to all Claude users.
- Rolling out to Team and Enterprise plan users starting today. Enterprise admins can choose whether to disable memory for their organization at any time.

## Memory built for work

- Claude focuses on learning professional context and work patterns. Remembers team's processes, client needs, project details, and priorities.
- **If you use projects, Claude creates a separate memory for each project.** Ensures product launch planning stays separate from client work, confidential discussions separate from general operations. Project boundaries serve as a safety guardrail.
- **Memory summary:** Claude uses a memory summary to capture all its memories in one place to view and edit. In settings you can see exactly what Claude remembers and update the summary at any time by chatting with Claude. Based on what you tell Claude to focus on or ignore, Claude adjusts the memories it references.

## Incognito chat

Gives a clean slate for conversations you don't want to preserve in memory. Perfect for sensitive brainstorming, confidential strategy discussions, or fresh conversation without context from previous chats. Regular memory and conversation history remain untouched.

## Getting started

Enable the feature in Settings, and let Claude generate memory with your past chats at initial set-up. Ask questions like "what were we working on last week?" Memory import/export supported (bring memory from a different AI tool or export for backup/migration).
