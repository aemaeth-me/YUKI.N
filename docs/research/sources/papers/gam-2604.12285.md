# GAM: Hierarchical Graph-based Agentic Memory for LLM Agents

- **arXiv**: 2604.12285 (cs.AI) | 2026-04-14 | ACL 2026 Long
- **作者**: Zhaofen Wu, Hanrong Zhang, Fulin Lin, Wujiang Xu, Xinran Xu, Yankai Chen, Henry Peng Zou, ... Philip S. Yu, Hongwei Wang
- **本地原始资料**: `sources/papers/gam-2604.12285.html`（arxiv HTML 全文）

## 核心思想
显式解耦 **记忆编码（encoding）** 与 **记忆巩固（consolidation）**，以化解"快速上下文感知"与"稳定知识保留"之间的冲突。灵感来自睡眠依赖的记忆巩固，用语义事件触发（semantic-event-triggered）的有限状态机驱动记忆从临时缓冲升迁到长期图网络。

## 记忆架构
- **两层图**：
  - 全局 Topic Associative Network（G_topic）：持久主题/语义簇，边为 LLM 打分的语义关系；
  - 局部 Event Progression Graph（G_event）：实时对话的原子事件（utterance/action）与其时序-因果边的 append-only 缓冲；
  - 跨层关联 E_cross：主题节点 → 归档事件子图快照的索引。
- **状态机巩固**：Episodic Buffering State（写入隔离，防瞬时噪声污染全局）→ 检测语义分歧指标 b_t（LLM 判别器，约 2048 token 缓冲）→ Semantic Consolidation State（将缓冲摘要成 c_sum(摘要)+c_raw(逐字证据) 双组件节点，coarse-to-fine 合并进 G_topic，归档并重置缓冲）。
- **检索**：Graph-Guided Multi-Factor Retrieval——语义锚点 + 一阶邻居扩展 → 跨层下钻到归档事件图 → 语义概率 × 时间对齐 × 角色一致 × 置信度四因子重排（β_time=1.4, β_role=1.4, β_conf=1.2）。

## 创新点
1. 把 consolidation 显式建模为"语义边界触发的原子操作"，而非固定窗口/时间阈值——这是对 stream 记忆噪声干扰问题的结构性解法。
2. 双组件节点（摘要+逐字证据）同时保高层抽象与可回溯证据。
3. 效率与效果双优：LoCoMo Qwen2.5-7B 平均 F1 40.00（Mem0 35.38），LongDialQA 12.55 vs MemoryOS 6.76；token 消耗最低。

## 局限
- 仅文本单模态（作者自陈将扩展多模态）。
- 语义分歧检测依赖 LLM 判别器，阈值/触发仍需调参。

## 对 Memory 设计的意义
"写入隔离缓冲 + 语义触发巩固"是解决记忆写入噪声/一致性污染的最佳实践之一；其"摘要+原始证据"双表示与多因子重排检索可直接借鉴到分层记忆检索设计。
