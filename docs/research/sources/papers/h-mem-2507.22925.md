# H-MEM: Hierarchical Memory for High-Efficiency Long-Term Reasoning in LLM Agents

- **arXiv**: 2507.22925 (cs.CL) | 2025-07-23
- **作者**: Haoran Sun, Shaoning Zeng
- **本地原始资料**: 搜索结果摘要（无本地 HTML；arxiv.org/html/2507.22925）

## 核心思想
针对向量检索"记忆条目增多后相似度计算量飙升"的问题，提出按语义抽象度组织的**分层记忆（H-MEM）**：每层记忆向量嵌入指向下一层子记忆的位置索引编码，检索时用索引路由逐层下钻，避免穷举相似度计算。

## 记忆架构
- **四层结构**（按语义抽象度）：对应 section/subsection/subsubsection/content 的层次。
- **索引编码**：每层记忆向量的 position index 指向其语义相关的下一层子记忆。
- **检索**：上层语义信息先筛选相关记忆单元，再逐层下钻到子记忆，减少无关信息参与范围。
- **评测**：LoCoMo 五种任务，优于五种基线（LoCoMo、ReadAgent、MemoryBank、MemGPT、A-MEM）。

## 创新点
1. "位置索引 + 逐层路由"让检索复杂度与记忆规模解耦，结构化且高效。
2. 用语义抽象度而非时间维度组织层次。

## 局限
- 层次分配依赖摘要质量，更新层次结构成本未详述。
- 相对 2026 年 GAM 等更成熟的分层图方法，机制较简单。

## 对 Memory 设计的意义
当记忆库规模大、要求低延迟时，"层级语义索引 + 逐层路由"可显著降低检索开销；可作为图记忆外的轻量替代。
