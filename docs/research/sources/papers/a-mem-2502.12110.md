# A-MEM: Agentic Memory for LLM Agents

- **arXiv**: 2502.12110 (cs.CL) | 2025-02-17 | NeurIPS 2025 | GitHub: WujiangXu/AgenticMemory、A-mem-sys
- **作者**: Wujiang Xu, Zujie Liang, Kai Mei, Hang Gao, Juntao Tan, Yongfeng Zhang
- **本地原始资料**: `sources/papers/a-mem-2502.12110.html`（arxiv HTML 全文）

## 核心思想
受 **Zettelkasten 卡片盒笔记法** 启发，构建自组织、自演化的 agentic memory：不依赖预定义结构/固定操作，每次写入生成带多属性的"笔记"，并动态建链、演化已有记忆。

## 记忆架构
- **Note Construction（写入）**：新交互生成综合笔记 mn，含结构化文本属性（contextual description、keywords、tags）+ 嵌入向量。
- **Link Generation（索引/建链）**：新笔记入库后按嵌入相似度检索近邻，由 LLM 判断是否与历史笔记建立连接；笔记可同时存在于多个"盒子"（语义簇）。
- **Memory Evolution（更新/遗忘）**：新记忆整合触发对近邻记忆的上下文/关键词/标签更新，使知识网络持续精炼。
- **Retrieve（检索）**：查询嵌入 → 相似度检索 → 返回相关历史记忆辅助生成。

## 创新点
1. 把人类笔记法（Zettelkasten）映射为 agent 记忆的"原子笔记 + 动态链接 + 关联演化"，概念新颖且落地完整。
2. 全动态：无需预定义记忆操作/存储点，适配多样化任务。
3. 跨 6 个基础模型验证，比 SOTA 基线（MemGPT、MemoryBank、ReadAgent、LoCoMo）在 LoCoMo/DialSim 上更好，Multi-Hop 尤为突出。

## 局限
- 每次写入都要 LLM 判链，写入路径成本高、延迟大。
- 缺乏显式遗忘/一致性管理；多模型对比在 GPT 上优势收窄。
- 记忆演化依赖相似度近邻，长程关联可能漏链（后续 GAM/图方法对此做了针对性改进）。

## 对 Memory 设计的意义
提供"链接式记忆 + 记忆间相互更新"的设计语言：当记忆库需要支持概念间的涌现关联时，A-MEM 的 note/link/evolution 三件套是性价比很高的起点。
