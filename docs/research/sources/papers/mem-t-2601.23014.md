# Mem-T: Densifying Rewards for Long-Horizon Memory Agents

- **arXiv**: 2601.23014 (cs.CL) | 2026-01 | v2
- **作者**: 未署名作者组（Hierarchical memory agent + MoT-GRPO）
- **本地原始资料**: `sources/papers/mem-t-2601.23014.html`（arxiv abs 页）

## 核心思想
针对 RL 记忆 agent 的"稀疏延迟奖励 + 长操作链 credit assignment 困难"，提出 **Memory Operation Tree-guided GRPO (MoT-GRPO)**：用记忆操作树分支拓扑把稀疏终局奖励反传为稠密 step-wise 监督，并对记忆构造做事后信用分配（hindsight credit assignment），联合优化记忆的构建与检索。

## 记忆架构
- **分层记忆数据库**：formation（形成）+ evolution（演化）操作维护层次化记忆，retrieval 操作做多轮自主搜索。
- **MoT-GRPO（检索侧）**：构建多个 Memory Operation Tree 探索多样轨迹，沿树回溯奖励到中间节点，产出稠密过程信号。
- **MoT-GRPO（构造侧）**：把 MoT 的效用归因回源记忆条目（hindsight credit assignment），监督 formation/evolution 操作。

## 创新点
1. 用"树引导"把时序信用分配从顺序链扩展到分支拓扑，缓解 RL 记忆管理中最大的训练难题。
2. 双轨训练：检索与构造联合优化，互喂信号。
3. LoCoMo Qwen3-4B/8B 上 F1 较 A-Mem/Mem0 提升 14.92/14.55（+34%/+33%）；推理 token 比 GAM 少约 24.45% 而不损性能。

## 局限
- 训练框架复杂（MoT 树构造成本）。
- 依赖 GRPO 基建与较长 rollout。

## 对 Memory 设计的意义
当我们的 memory 体系引入 RL 训练时，MoT-GRPO 的"操作树 + 事后归因"是处理记忆操作长链稀疏奖励的首选方案；训练免费模式下其分层记忆数据库设计亦可直接复用。
