# MEM1: Learning to Synergize Memory and Reasoning for Efficient Long-Horizon Agents

- **arXiv**: 2506.15841 (cs.CL) | 2025-06-18 (v1)；2025-07-17 v2
- **作者**: Zijian Zhou, Ao Qu, Zhaoxuan Wu, Sunghwan Kim, Alok Prakash, Daniela Rus, Jinhua Zhao, Bryan Kian Hsiang Low, Paul Pu Liang（MIT）
- **本地原始资料**: `sources/papers/mem1-2506.15841.html`（arxiv HTML 全文）

## 核心思想
用端到端 RL 训练 agent 以**恒定内存**（constant memory）跨长多轮任务运行：每轮更新一个紧凑的共享内部状态，该状态同时承担记忆巩固与推理两个职能，战略性地丢弃无关/冗余信息，替代"全量上下文拼接"。

## 记忆架构
- **单一共享状态**：mem 内部状态整合旧记忆 + 新观测，兼作 reasoning 的工作记忆。
- **组成式多轮环境构建**：把现有数据集组合成任意复杂任务序列（用于训练）。
- **训练**：GRPO 风格 RL，目标为任务成功率与内存效率的双重奖励。
- **评测域**：内部检索 QA、开放域 Web QA、多轮 Web 购物。

## 创新点
1. "记忆与推理协同"的单一状态设计——记忆不再是外部附件而是推理本身的一部分。
2. 恒定内存：MEM1-7B 相对 Qwen2.5-14B-Instruct 在 16 目标多跳 QA 任务上性能提升 3.5x、内存占用降低 3.7x，且泛化超出训练视界。

## 局限
- 状态压缩必然丢失细节，适合"决策型"而非"高保真事实回忆型"任务。
- 组成式训练环境与真实用户交互有差距。

## 对 Memory 设计的意义
对"上下文预算受限"的 agent 场景（如编码 agent、web 操作），"折叠式恒定状态 + RL"是替代无限增长历史的高性价比范式；但需与外部保真存储配合（该综述即持此观点）。
