# AI Meets Brain: A Unified Survey on Memory Systems from Neuroscience

- **arXiv**: 2512.23343 | 2025-12-29
- **作者**: 未署名作者组
- **本地原始资料**: 搜索结果摘要（无本地 HTML；arxiv.org/html/2512.23343）

## 核心思想
以脑科学为统一透镜综述 AI 记忆：短期记忆依赖 frontoparietal 网络、长期记忆依赖海马-新皮层协调，并据此对 agent 记忆做存储/调度/检索/更新的系统映射。整合"启发式上下文设计 → 自主记忆优化（RL）→ 潜变量记忆"的发展脉络。

## 记忆架构（脑科学映射）
- **存储层级映射**：context window = 临时记忆（工作记忆）；外部结构化存储 = 长期记忆。
- **调度机制**：时间片/多级缓存（借鉴 OS 进程调度，Zou et al.）；学习式自适应调度（IGP-PPO 选调度规则）；RL 长文本流管理（MemAgent 式覆盖式记忆）。
- **记忆折叠（memory folding）**：上下文内记忆机制——周期性摘要压缩（Wu et al.）、触发 token 决定是否折叠（Li et al.）、上下文折叠技能化（Ye et al., context folding）。
- **潜变量记忆**：MemoryLLM / M+（各层固定潜向量作"内部记忆"，随上下文迭代检索更新）；Weaver（agent 记忆，触发模块决定何时调用潜记忆）。

## 创新点
1. 神经科学 → AI 记忆的系统映射，覆盖 2025 出现的 memory folding、潜变量记忆新趋势。
2. 把"调度/分层/自适应学习"整理为记忆系统三大动态机制。

## 局限
- 综述类，无统一实验。
- 脑科学映射部分类比性强于操作性。

## 对 Memory 设计的意义
"记忆折叠（folding）"与"潜变量记忆"提示我们：除显式图/向量存储外，上下文内的压缩式工作记忆与潜在向量记忆是两类值得追踪的补充机制。
