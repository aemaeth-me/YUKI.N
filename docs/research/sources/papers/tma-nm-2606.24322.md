# TMA-NM: Securing LLM-Agent Long-Term Memory Against Poisoning — Non-Malleable, Origin-Bound Authority

- **arXiv**: 2606.24322 (cs.CR) | 2026-06
- **作者**: 未署名作者组
- **本地原始资料**: 搜索结果摘要（无本地 HTML；ar5iv.labs.arxiv.org/html/2606.24322）

## 核心思想
研究记忆投毒（memory poisoning）：攻击者在某会话存入不可信内容，日后诱导 agent 执行付款/改设置/数据外泄等关键动作。证明基于**内容（trust-scoring）或谱系（lineage）**的现有防御都可被"洗白（laundering）"绕过，并提出机器验证的分离定理。

## 记忆架构（安全模型）
- **三条洗白通道**：自我摘要（agent 自己改写投毒内容）、可信工具回声（工具返回攻击者内容）、制造佐证（多个不可信条目伪造共识）。
- **分离定理**：内容/谱系防御在洗白下不健全（T1）；写时绑定源（write-time origin binding）是必要的（T2）；不可变源绑定权威 + Sybil 抗性佐证门控提升是充分的（T3）。
- **TMA-NM 构造**：非可变态信息流控制（IFC）实例化——记忆条目权威绑定真实源，标签不可变，且沿派生传播；权威仅能通过 ≥2 个独立可信主体佐证或新鲜的用户动作授权提升；全部判定附加在防篡改哈希链上。

## 关键结果（论文口径）
跨 8 个前沿模型：现有防御在理论预测处失败（洗白攻击成功率达 68%）；TMA-NM 在直接与洗白攻击下均 0% 成功率，合法效用 100%；附 TLA+ 机器验证模型。

## 创新点
1. 把"记忆权威"从内容可信度重构为**源绑定信息流控制**，并给出可机器检查的安全性证明。
2. 完整覆盖三种实际洗白通道并验证理论预测。

## 局限
- 面向安全关键动作（consequential action）场景，对普通对话记忆侵入性过强。
- 依赖可信监控器记录源通道。

## 对 Memory 设计的意义
安全基线建议：对执行"有副作用动作"的记忆条目，记录其来源通道并继承来源可信度；升级权威需多方佐证或用户授权——可轻量化引入（来源元数据）而不必全量 IFC。
