# 01 快速上手

## 启动

```console
export DEEPSEEK_API_KEY=...
./yuki
```

浏览器打开 <http://127.0.0.1:15173>。首次启动自带一位名为 `Yuki` 的默认
人格，可以直接使用。

## 第一次使用（两分钟）

1. **集群总览**：你会看到 Yuki 卡片，状态为「空闲」。点卡片进入工作台。
2. **主对话**：顶部导航点「主对话」，随便聊一句，例如「介绍一下你自己」。
   回答流式出现；这就是这位 Yuki 的主 Agent。聊天不会创建任何任务。
3. **派发一个任务**：点对话头部的「派发任务」，输入需求，例如
   「在当前目录找一个拼写错误并修复」。系统会生成一份草案：标题、任务
   Prompt、能力快照。可以改了再确认，也可以直接「确认派发」。
4. **观察执行**：页面跳到该任务的对话，任务 Agent 开始工作。回到「现在」
   视图，你能看到任务 Run 的状态卡：轮次、token、上下文、正在执行的
   工具；如果它派出了 Worker，Worker 会缩进显示在下方。
5. **介入**：任何状态卡都可以 [steer] 注入一句引导，或 [取消] 终止。
6. **看结果**：执行完，去「交付」看答案与写出的文件，去「变更」看文件
   diff。

## 每天的工作方式

- 有小事：直接在主对话说。主 Agent 自己干，或临时派 Worker 干。
- 有正事：派发任务。任务有独立对话，可暂停、可继续、可归档（经 API）。
- 走开一会儿：集群总览的卡片会告诉你谁在跑、谁在等你确认。
- 不确定动过什么文件：「变更」视图按时间列出全部改动与 diff。

## 停下来

启动器窗口里 `Ctrl-C`，前后端一起停止。所有对话、任务、派发草案、
交付与变更记录都持久在本地（默认 `~/.yuki-n`），下次启动原样恢复
（进行中的 Run 不恢复——它只活在进程内）。
