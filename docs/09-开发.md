# 09 开发

## 构建与测试

```console
cabal build all && cabal test all            # 后端（367 项测试）
fourmolu --mode inplace $(git ls-files '*.hs')
hlint src app test
cd frontend && npm ci && npm run build       # Elm → frontend/dist
cd frontend && npm test                      # JS 测试（node:test）
cd frontend && node test/smoke.mjs           # Playwright 全栈冒烟（可选）
```

CI 拒绝未格式化代码与 HLint error。

## 代码地图

```text
src/Yuki/N/
  Agent.hs          Run 主循环（模型轮次、工具执行、终局、cascade、遥测接入）

  Runs.hs           Run 注册表：树索引、steering 队列、完成表
  Telemetry.hs      LiveStatus 投影、ActivityHub、台账类型
  Telemetry/Ledger.hs  交付/变更台账（jsonl）与 git 增强
  Dispatch.hs       派发草案 store、生成、confirm 事务
  DispatchTool.hs   propose_dispatch 工具
  Dispatch/Types.hs  派发纯类型（leaf）
  Sessions.hs       主对话/任务元数据（SessionKind）
  ThreadConfig.hs   任务级配置与 runtime 解析、fs 工具拦截
  ThreadConfig/Types.hs  配置纯类型（leaf）

  Main.elm              壳：路由、端口、遥测订阅
  Yuki/Telemetry/*      监控流类型/解码/状态
```

## 测试约定

- 测试按领域拆分在 `test/Yuki/N/*Test.hs`，`test/Main.hs` 只注册。
- 属性测试用 tasty-quickcheck（每条 ≤200 次）。
- golden：`test/golden/*.jsonl` 录制回放；工具列表变化时按既有流程
  再生成并核对 diff 为纯增量。
- 前端：`frontend/test/*.test.mjs`（node:test）。
